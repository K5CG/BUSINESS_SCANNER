## Build requirements

Mac, Xcode, Apple Developer account, CocoaPods, `npx expo prebuild --platform ios`, `pod-install`, native modules. **Not Expo Go** (ML Kit + camera patch).

### Camera patch (mandatory)

`package.json` `postinstall` runs `scripts/patch-expo-camera-focus.mjs`.

That script patches **Android/Kotlin and iOS/Swift** inside `node_modules/expo-camera`. After `npm install`, confirm it ran. `expo.autolinking.buildFromSource` includes `expo-camera` so the patch is compiled.

1. App launches  
2. Scan one business card  
3. Scan ThermoFlux, 2 pages  
4. OCR geometry usable (lines have frames; parser not rewritten)  
5. Save / reopen SQLite

Only after these pass start StoreKit / App Store work. See `docs/PURCHASE_PROVIDER_CROSS_PLATFORM_SPEC.md`. License keys are not the final iOS consumer purchase mechanism.

## Exit / privacy

`lib/app-exit.ts` → `exitAppSession()`. Android ends the activity. **iOS must not force-quit.** Home exit and privacy decline both use this helper. On iOS, `attempted: false` is expected; the UI stays put.
